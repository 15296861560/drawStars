# 问卷管理系统 — 产品需求设计文档（PRD）

> **项目**: drawStars (Vue3)
> **版本**: v1.1
> **日期**: 2026-08-05
> **状态**: 补充更新（+统计分析深化 / +评分模式开关）

---

## 一、需求背景与目标

### 1.1 背景

当前 drawStars 平台已具备用户管理、权限体系、AI 助手等基础能力，但缺少用户调研和数据收集手段。问卷管理模块旨在为平台提供一套**可自助创建、分发、回收、分析**的问卷工具，服务于以下场景：

- 用户满意度调研
- 功能需求收集
- 活动报名/反馈
- 内部信息统计

### 1.2 设计目标

| 目标       | 说明                                                 |
| ---------- | ---------------------------------------------------- |
| **易用**   | 创建者无需技术背景，通过可视化编辑器拖拽生成问卷     |
| **灵活**   | 支持多种题型、逻辑跳转、分页、定时发布等高级能力     |
| **可扩展** | 题型、分发渠道、分析维度均可后续扩展，不改动核心流程 |
| **安全**   | 支持匿名/实名、IP 限制、设备限制、填写次数控制       |

### 1.3 不在本期范围

- 付费问卷 / 红包激励
- 问卷模板市场（本期仅支持预置模板）
- 多人协作编辑同一问卷

## 二、用户角色

| 角色           | 说明                                                 | 核心诉求                     |
| -------------- | ---------------------------------------------------- | ---------------------------- |
| **平台管理员** | 拥有全部权限，管理所有问卷、查看全局数据             | 管控、审计、全局统计         |
| **问卷创建者** | 创建/编辑/发布自己名下的问卷，查看自己问卷的回收数据 | 快速创建、方便分发、直观分析 |
| **填写者**     | 通过链接/二维码填写问卷，无需登录（或可选登录）      | 填写流畅、移动端友好         |

> 角色与现有 RBAC 权限体系集成，通过菜单权限 `survey:questionnaire:list` 等控制可见性。

## 四、各模块详细设计

### 4.1 问卷设计器

#### 4.1.1 题目管理

| 功能     | 说明                                                |
| -------- | --------------------------------------------------- |
| 添加题目 | 从题型库选择题型，插入到指定位置                    |
| 编辑题目 | 修改题干、选项、必填状态、分值等                    |
| 排序题目 | 拖拽排序，支持批量移动                              |
| 复制题目 | 复制单题到当前问卷或其他问卷                        |
| 删除题目 | 删除后逻辑关联自动解除并提示                        |
| 题目分组 | 支持将题目按"分页/分组"组织，每组可设独立标题和描述 |

#### 4.1.2 题型库

**基础题型（v1.0）：**

| 题型      | 说明                      | 特殊配置               |
| --------- | ------------------------- | ---------------------- |
| 单选题    | 单选，支持"其他"自由填写  | 选项数量不限           |
| 多选题    | 多选，可设最少/最多选择数 | 可选限制范围           |
| 填空题    | 单行文本输入              | 正则校验、字数限制     |
| 多行填空  | 多行文本输入              | 字数限制               |
| 数字输入  | 仅接受数字                | 整数/小数、范围限制    |
| 评分题    | 星级/数字评分             | 评分制（5星/10分/NPS） |
| 日期/时间 | 日期选择器                | 日期范围限制           |
| 图片上传  | 上传图片作为答案          | 格式/大小限制          |

**高级题型（v1.1+ 扩展预留）：**

| 题型     | 说明               |
| -------- | ------------------ |
| 矩阵单选 | 多行共用同一组选项 |
| 矩阵填空 | 表格形式多字段填写 |
| 排序题   | 对选项进行排序     |
| 滑动条   | 区间滑动选择       |
| 文件上传 | 上传任意文件       |
| 签名题   | 手写签名           |
| 定位题   | 获取地理位置       |

> **扩展机制**：题型通过注册表模式管理。每种题型实现统一接口（渲染组件 + 校验规则 + 数据序列化），新增题型只需注册，不影响已有逻辑。

#### 4.1.3 逻辑编排

| 能力     | 说明                               |
| -------- | ---------------------------------- |
| 显示逻辑 | 当 Q1 选择 A 时，显示 Q3；否则隐藏 |
| 跳转逻辑 | 当 Q2 选择 B 时，跳到第 3 页       |
| 选项逻辑 | 当选择"其他"时，展开填空框         |
| 必填逻辑 | 当 Q1 有值时，Q2 变为必填          |

逻辑规则以 **条件 → 动作** 的形式建模：

```text
条件：{ 题目ID, 运算符(等于/包含/大于/...), 值 }
动作：{ 类型(显示/隐藏/跳转/必填), 目标题目ID, 目标页码 }
```

支持多条件 AND/OR 组合。

#### 4.1.4 外观设置

| 配置项   | 说明                       |
| -------- | -------------------------- |
| 主题色   | 主色调、背景色             |
| 背景     | 纯色 / 图片 / 预设模板     |
| 进度条   | 显示/隐藏，样式选择        |
| 题号     | 显示/隐藏                  |
| 按钮文案 | "下一页/上一页/提交"自定义 |
| 感谢页   | 提交后的感谢语 + 跳转链接  |

### 4.2 问卷管理

#### 4.2.1 生命周期

```text
草稿 ──→ 已发布 ──→ 已暂停 ──→ 已发布（恢复）
  │         │                      │
  │         └──→ 已结束 ←──────────┘
  │
  └──→ 已删除（软删除）
```

| 状态   | 说明                   | 可执行操作           |
| ------ | ---------------------- | -------------------- |
| 草稿   | 编辑中，不可填写       | 编辑、发布、删除     |
| 已发布 | 可被填写               | 暂停、结束、查看数据 |
| 已暂停 | 暂停填写，已有数据保留 | 恢复发布、结束       |
| 已结束 | 不可填写，不可恢复     | 查看数据、导出、复制 |

#### 4.2.2 发布配置

| 配置项       | 说明                                   |
| ------------ | -------------------------------------- |
| 发布时间     | 立即 / 定时发布                        |
| 截止时间     | 不限 / 指定日期自动结束                |
| 最大份数     | 不限 / 达到上限自动结束                |
| 填写限制     | 每人限填次数（基于登录态/IP/设备指纹） |
| 是否需要登录 | 必填 / 选填 / 不需要                   |
| 密码访问     | 可选，设置填写密码                     |
| 白名单       | 指定用户/部门才可填写（内部调研场景）  |

#### 4.2.3 分享与分发

| 方式     | 说明                           |
| -------- | ------------------------------ |
| 链接分享 | 生成唯一短链，支持带参追踪来源 |
| 二维码   | 自动生成二维码图片，可下载     |
| 站内消息 | 通过平台通知系统推送给指定用户 |
| 嵌入页面 | 生成 iframe 嵌入代码           |

### 4.3 问卷填写

#### 4.3.1 填写引擎

- 逐页展示（分页模式）或长页面展示（单页模式），创建者可选
- 实时校验：必填检查、格式校验、逻辑校验
- 移动端适配：响应式布局，触屏友好
- 题目渲染根据逻辑规则动态显隐

#### 4.3.2 断点续填

- 未登录用户：基于 localStorage 暂存，7 天有效
- 已登录用户：服务端保存进度，跨设备续填
- 提交前可保存为"暂存"，下次继续

#### 4.3.3 防作弊控制

| 策略     | 说明                           |
| -------- | ------------------------------ |
| IP 限制  | 同一 IP 最多填写 N 次          |
| 设备指纹 | 基于浏览器指纹限制填写次数     |
| 答题时长 | 低于最短时长视为无效（可配置） |
| 查重     | 开放题文本相似度检测（v1.1+）  |

### 4.4 数据统计与分析

> 统计分析是问卷系统的核心价值输出。设计原则：**实时计算 + 异步聚合**，小数据量实时响应，大数据量（>1000 份）走异步任务队列，完成后通知查看。

#### 4.4.1 统计概览（Dashboard）

**核心指标卡片：**

| 指标     | 说明                 | 计算方式                         |
| -------- | -------------------- | -------------------------------- |
| 回收份数 | 总提交 / 有效 / 无效 | `COUNT(response)` 按 status 分组 |
| 回收率   | 回收份数 / 分发次数  | 分发次数 = 链接点击数或推送人数  |
| 完成率   | 已提交 / 已开始填写  | 含中途放弃的统计                 |
| 平均用时 | 填写者平均耗时       | `AVG(duration)` 仅计有效答卷     |
| 中位用时 | 排除极端值的典型耗时 | `PERCENTILE_CONT(0.5)`           |
| 今日新增 | 当日提交份数         | 实时刷新                         |

**趋势图表：**

| 图表          | 说明                              | 交互                   |
| ------------- | --------------------------------- | ---------------------- |
| 回收趋势      | 按日/时的提交量折线图             | 支持缩放、时间范围选择 |
| 来源分布      | 各渠道来源占比饼图                | 点击扇区筛选           |
| 地域分布      | 按省份/城市的填写热力图           | 地图可视化             |
| 设备分布      | PC / 移动端 / 平板占比            | 环形图                 |
| 时段分布      | 24 小时 × 7 天的填写热力图        | 识别最佳投放时段       |
| 完成/放弃漏斗 | 开始 → 第1页 → 第2页 → ... → 提交 | 定位流失页面           |

**实时性保证：**

- 提交后 5 秒内概览数据刷新（短轮询或 WebSocket 推送）
- 统计缓存策略：Redis 缓存聚合结果，答卷提交时增量更新
- 大数据量（>5000 份）切换为 T+1 离线聚合 + 实时增量

#### 4.4.2 单题分析

| 题型     | 展示方式              | 统计指标                                 |
| -------- | --------------------- | ---------------------------------------- |
| 单选     | 柱状图 + 饼图可切换   | 各选项计数、占比、排名                   |
| 多选     | 柱状图（横向）        | 各选项选择次数、占比、平均选择数         |
| 填空     | 词云 + 文本列表       | 高频词 TOP20、平均字数、空答率           |
| 多行填空 | 文本列表 + 关键词高亮 | 同上                                     |
| 数字     | 箱线图 + 分布直方图   | 均值、中位数、标准差、最大/最小、P25/P75 |
| 评分     | 平均分 + 分布直方图   | 均值、NPS 值、各星级占比                 |
| 日期     | 时间线分布            | 日期集中度                               |
| 图片上传 | 缩略图网格            | 上传数量统计                             |
| 矩阵     | 热力图矩阵            | 行列交叉分布                             |
| 排序     | 平均排名 + 排名分布   | 各选项平均排位、一致性系数               |

**单题通用能力：**

- 支持按筛选条件查看（如"只看男性填写者的 Q2 分布"）
- 支持查看原始答案列表（点击图表元素下钻）
- 空答率独立统计，与有效答案分开计算

#### 4.4.3 交叉分析

支持选择两个或多个维度进行交叉对比：

**预设交叉场景：**

| 场景     | 维度 A         | 维度 B      | 输出                   |
| -------- | -------------- | ----------- | ---------------------- |
| 人群差异 | 性别/年龄/地区 | 任意题目    | 不同人群的答题分布差异 |
| 来源对比 | 分发渠道       | 满意度评分  | 各渠道的满意度差异     |
| 时间对比 | 提交日期段     | 任意题目    | 不同时期的答案变化趋势 |
| 设备对比 | PC vs 移动端   | 完成率/用时 | 设备对填写体验的影响   |

**输出形式：**

- 交叉表格（行×列 + 计数/百分比）
- 堆叠柱状图（直观对比分布差异）
- 统计显著性检验（卡方检验，v1.1+ 可选）

**操作方式：**

1. 选择"行维度"（题目或元数据字段）
2. 选择"列维度"（题目或元数据字段）
3. 选择统计值（计数 / 行百分比 / 列百分比 / 总百分比）
4. 生成报表，可保存为自定义报表

#### 4.4.4 筛选与对比分析

**答卷筛选器：**

- 按提交时间范围
- 按填写者属性（用户 ID、部门、地区）
- 按来源渠道
- 按任意题目的答案值（如"Q1 选择了 A 的答卷"）
- 按填写时长范围（如"用时 > 5 分钟的答卷"）
- 按有效/无效状态

筛选结果应用于所有统计图表，实现**动态下钻**。

**对比分析：**

- 支持创建"分析视图"并保存筛选条件
- 支持两个视图并排对比（如"活动前 vs 活动后"）
- 对比结果自动计算差异值和变化率

#### 4.4.5 数据质量分析

| 维度       | 说明                                    | 处理方式             |
| ---------- | --------------------------------------- | -------------------- |
| 无效卷标记 | 用时过短、规律性作答（全选 A）、IP 异常 | 自动标记 + 人工审核  |
| 重复卷检测 | 相同 IP + 相同答案模式                  | 标记疑似重复         |
| 开放题质量 | 字数过少、纯符号、复制粘贴检测          | 质量评分（高/中/低） |
| 缺失分析   | 各题空答率统计                          | 识别导致放弃的题目   |
| 异常值检测 | 数值题的离群值                          | 箱线图标注           |

**数据清洗操作：**

- 批量标记为无效（不删除，仅排除出统计）
- 一键排除所有自动标记的无效卷
- 清洗操作记录审计日志，可回退

#### 4.4.6 自定义报表

- 创建者可选择需要展示的题目和统计维度，生成自定义报表视图
- 报表可保存、分享链接、导出
- 支持定时生成报表并发送到邮箱/站内消息（v1.1+）
- 报表模板：可保存常用报表配置，下次一键生成

#### 4.4.7 数据导出

| 格式  | 说明                    | 包含内容                            |
| ----- | ----------------------- | ----------------------------------- |
| Excel | 每行一份答卷，每列一题  | 原始数据 + 元数据（时间、IP、设备） |
| CSV   | 同上，CSV 格式          | 同上                                |
| PDF   | 统计报告                | 概览 + 图表 + 关键发现              |
| JSON  | 结构化原始数据          | 便于二次开发/导入其他系统           |
| SPSS  | 标准 .sav 格式（v1.1+） | 含变量标签和值标签                  |

**导出选项：**

- 仅有效答卷 / 包含无效 / 全部
- 含/不含元数据（IP、设备等）
- 编码选择（UTF-8 / GBK）
- 大数据量（>10000 份）异步生成，完成后通知下载

### 4.5 评分模式（可开关）

> 问卷系统不仅用于调研，还可用于考试、测评、知识测验等场景。评分模式通过**问卷级开关**控制，开启后为问卷赋予评分、判分、成绩管理等能力，不影响普通问卷流程。

#### 4.5.1 评分开关与全局配置

**开关位置：** 问卷编辑器 → 顶部设置栏 → "评分模式"开关

| 配置项       | 说明                                         | 默认值                   |
| ------------ | -------------------------------------------- | ------------------------ |
| 评分模式     | 开/关                                        | 关                       |
| 评分方式     | 手动赋分 / 自动判分 / 混合                   | 自动判分                 |
| 满分         | 自动计算或手动指定                           | 自动（所有题目分值之和） |
| 及格分       | 用于判定是否通过                             | 满分的 60%               |
| 及格线显示   | 是否在提交后展示                             | 显示                     |
| 成绩可见性   | 提交后立即显示 / 指定时间公布 / 仅管理员可见 | 提交后立即显示           |
| 查看正确答案 | 提交后是否展示正确答案和解析                 | 不展示                   |
| 重考策略     | 允许多次 / 取最高分 / 取最后一次 / 取平均分  | 取最高分                 |
| 最大重考次数 | 限制重考次数（0=不限）                       | 0                        |
| 重考冷却时间 | 两次考试之间的最短间隔                       | 0（无限制）              |

**开关行为：**

- 关闭评分模式：问卷为纯调研模式，不显示任何评分相关配置
- 开启评分模式：编辑器中出现"赋分"面板，题目属性中增加分值设置，统计分析中增加成绩维度
- 状态切换不影响已回收数据，仅影响后续填写流程

#### 4.5.2 题目赋分

**自动判分题型（有标准答案）：**

| 题型   | 赋分方式                     | 说明                       |
| ------ | ---------------------------- | -------------------------- |
| 单选题 | 每题固定分值                 | 选对得满分，选错得 0       |
| 多选题 | 全对满分 / 漏选半分 / 错选 0 | 可配置评分策略             |
| 填空题 | 精确匹配 / 模糊匹配          | 支持多个正确答案、正则匹配 |
| 判断题 | 固定分值                     | 对/错二选一                |

**手动赋分题型（需人工阅卷）：**

| 题型     | 赋分方式           | 说明               |
| -------- | ------------------ | ------------------ |
| 多行填空 | 人工打分           | 阅卷者逐份评分     |
| 图片上传 | 人工打分           | 根据上传内容评分   |
| 排序题   | 按正确顺序比例给分 | 可配置部分得分规则 |

**赋分配置存储：**

```json
// question.config 中的评分相关字段
{
  "scoring": {
    "enabled": true, // 该题是否参与评分
    "points": 10, // 满分值
    "scoring_type": "auto", // auto | manual | hybrid
    "correct_answer": {
      // 标准答案（自动判分时必填）
      "value": "option_2",
      "alternatives": [] // 填空题的多个正确答案
    },
    "partial_scoring": {
      // 多选题的半分规则
      "strategy": "half_for_missing", // half_for_missing | none | custom
      "wrong_penalty": 0 // 错选扣分（0=不扣）
    },
    "explanation": "解析文本..." // 提交后展示的解析
  }
}
```

#### 4.5.3 评分规则引擎

除了逐题打分，还支持**全局评分规则**，用于复杂评分场景：

| 规则类型 | 说明                  | 示例                                              |
| -------- | --------------------- | ------------------------------------------------- |
| 加权规则 | 不同题目/分区权重不同 | "第一部分占 30%，第二部分占 70%"                  |
| 条件加分 | 满足条件额外加分      | "Q5 回答正确额外 +5 分"                           |
| 扣分规则 | 特定行为扣分          | "超时每题扣 1 分"                                 |
| 等级映射 | 分数段映射为等级      | "90-100=优秀, 80-89=良好, 60-79=及格, <60=不及格" |
| 维度评分 | 按维度聚合分数        | "沟通能力: Q1+Q3+Q5 的平均分"                     |

**规则配置结构：**

```json
// survey.settings.scoring_rules
{
  "rules": [
    {
      "type": "weight",
      "description": "分区权重",
      "config": {
        "pages": { "1": 0.3, "2": 0.7 }
      }
    },
    {
      "type": "grade_mapping",
      "description": "等级映射",
      "config": {
        "ranges": [
          { "min": 90, "max": 100, "label": "优秀", "color": "#52c41a" },
          { "min": 80, "max": 89, "label": "良好", "color": "#1890ff" },
          { "min": 60, "max": 79, "label": "及格", "color": "#faad14" },
          { "min": 0, "max": 59, "label": "不及格", "color": "#ff4d4f" }
        ]
      }
    }
  ]
}
```

## 九、扩展性设计

### 9.1 题型扩展

采用**注册表模式**，每种题型是一个独立模块：

```text
types/
├── base.ts          ← 题型接口定义（渲染、校验、序列化）
├── radio.ts         ← 单选题实现
├── checkbox.ts      ← 多选题实现
├── input.ts         ← 填空题实现
└── ...              ← 新题型只需新增文件并注册
```

新增题型时：

1. 实现统一接口
2. 在注册表中注册
3. 前端编辑器自动识别

**无需修改**编辑器核心逻辑、存储结构、统计引擎。

### 9.2 分发渠道扩展

分发通过 **Channel 适配器** 模式扩展：

- 每个渠道实现统一接口（生成链接、推送消息、回调统计）
- 新增渠道只需实现适配器并注册

### 9.3 分析维度扩展

统计分析采用 **插件式分析器**：

- 基础分析器（频率、均值、分布）内置
- 高级分析器（词云、情感分析、趋势预测）可插拔注册

### 9.4 评分规则扩展

评分规则引擎采用**策略模式**：

- 每种规则类型（加权、等级映射、维度评分等）实现统一接口 `ScoringRule`
- 规则链按优先级顺序执行，最终聚合为总分
- 新增规则类型只需实现接口并注册，不影响已有评分流程

```typescript
// 评分规则接口
interface ScoringRule {
  type: string
  apply(context: ScoringContext): ScoringResult
}

// 评分上下文
interface ScoringContext {
  answers: Map<questionId, Answer>
  questions: Question[]
  response: Response
  currentScore: number // 上游规则计算后的分数
}
```

### 9.5 与现有系统集成点

| -------- | ---------------------------------------- |
| 用户体系 | 复用 userInfoStore，填写者关联 userId    |

| 通知系统 | 问卷发布时通过 notify 推送给目标用户     |
| 日志管理 | 关键操作写入操作日志                     |
| AI 助手  | 后续可通过 AI 助手智能生成问卷题目       |
