## 一、需求背景与目标

### 1.1 背景

drawStars 已具备 PC 管理端（用户、角色、菜单、应用管理等）与部分 H5/工具能力，但移动侧尚未形成统一「平台壳」：

- Android / iOS / H5 / 小程序能力分散，登录、账户、菜单、权限、消息体验不一致
- PC「应用管理」已支持应用元数据与安装包上传，但缺少面向移动端的**模块分发、安装、升级、运行**闭环
- 业务功能以 H5 开发为主时，缺少可复用的**容器运行时**（鉴权透传、菜单挂载、生命周期、版本管理）
- 平台壳自身缺少可控的**自动升级**机制，发版依赖应用商店或人工替换

本期建设「移动端统一平台（Mobile Shell / Container）」，在多端提供一致底座能力，并作为容器承载可热更新的 H5 功能模块。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **多端一致** | 各端共用账户/菜单/权限/消息**模型与主路径**；能力按端降级（不要求完全等价） |
| **底座完整** | 登录、账户设置、动态菜单、RBAC、**站内信闭环**；推送能力分端分版本落地（完整通道见 v1.1） |
| **容器化** | 平台作为容器承载 H5 功能模块；**App** zip 安装升级；**H5** 弱安装（清单/缓存）；**小程序仅在线打开**（不下 zip） |
| **与 PC 打通** | 模块包、版本、灰度、上下架由 PC 应用管理统一配置，移动端按端能力消费 |
| **可热更** | App/H5 模块可升级；壳支持强制/可选更新（App 可用 wgt/整包；小程序走平台更新机制） |
| **安全可控** | 鉴权、签名校验、权限码、域名白名单、敏感能力（相机/定位等）按端授权 |
| **可观测** | 安装成功率、启动耗时、崩溃/白屏、升级转化可统计并对接日志体系 |

### 1.3 不在本期范围

| 项 | 说明 |
|----|------|
| 完整原生业务重写 | 业务功能默认以 H5 模块交付，非必要不要求原生重写 |
| 独立应用商店运营（对外上架第三方 App） | 本期仅平台内「我的应用 / 应用中心」分发自有模块 |
| 完整小程序云开发 / 第三方小程序宿主 | 以 uni-app 编译的微信等小程序壳为主，不自建小程序宿主 |
| **小程序端 zip 下载与本地装模块** | **明确不做**；小程序仅通过 `web-view` 打开已配置的合规在线 H5 地址 |
| 完整 IM 聊天室能力 | 消息以系统通知/站内信为主；完整 IM 见《聊天体系_PRD》 |
| 多租户 SaaS 隔离 | 架构预留 `tenant_id`，完整多租户 v2.0+ |
| ABAC / 行级数据权限引擎 | 复用现有 RBAC；数据权限跟随《权限管理体系》演进 |
| 离线全量可用（无网可跑全部模块） | App v1.0 支持已装模块短时离线打开；小程序不承诺离线模块；完整离线策略 v1.2+（仅 App/H5） |

### 1.4 产品定位与架构原则

> **定位**：移动端统一平台 = **壳（Shell）** + **运行时（Runtime）** + **模块市场（Module Store）**。  
> 壳负责账号与系统能力；运行时负责加载 H5 模块；模块市场对接 PC 应用管理完成分发与升级。

#### 1.4.0 技术选型决策（uni-app）

> **v1.0 结论**：多端壳采用 **uni-app（Vue3）** 独立工程实现，一套代码编译至 App（Android/iOS）、H5、微信小程序等目标端；PC 管理端仍为现有 Vite 工程，**不合并仓库**。

| 决策项 | 结论 |
|--------|------|
| Shell 框架 | uni-app Vue3 |
| 工程形态 | **独立仓库**（建议名 `drawStars-uniapp`，与 drawStars-Vue3 分离） |
| 与 PC 关系 | 共用后端 API；**应用中心、菜单/权限等配置在 drawStars-Vue3 上复用并改造**，不在移动仓重复建设管理端 |
| Bridge | 优先封装 `uni.*` API；模块侧通过 Runtime 约定协议调用（App 可辅以 `web-view` postMessage） |
| 壳热更 | App：`wgt` 资源热更 + 整包/应用商店；H5：资源刷新；小程序：微信平台更新机制 |
| 模块分发 | **App**：zip 下载安装升级；**H5**：弱安装（清单/可选预取，**不下载 zip 凭证**）；**小程序**：仅在线打开 |

#### 1.4.1 逻辑架构

```
[uni-app Shell → Android / iOS / H5 / 小程序]
        |  HTTPS（登录/菜单/权限/消息/模块清单/升级）
        |  本地：Token、菜单；App 已装 zip；H5 弱安装清单/缓存
        v
[Mobile Shell · uni-app]
  |- Auth / Account
  |- Menu / RBAC Client
  |- Message Hub
  |- Update Manager（壳升级：wgt/整包/平台更新）
  |- Module Manager
  |    |- App：发现/下载 zip/安装/升级/卸载
  |    |- H5：发现/弱安装（清单）/在线打开
  |    +- 小程序：发现/添加入口/在线打开（无 zip）
        |
        v
[H5 Module Runtime]
  |- App：web-view 加载本地已装包（优先）或调试远程址
  |- H5：路由容器 / web-view / 缓存资源
  |- 小程序：web-view 仅加载业务域名 HTTPS 模块页
  |- Bridge（uni API + postMessage 协议）
  |- Auth / Lifecycle
        |
        v
[API Gateway]
  |- 用户 / RBAC / 通知
  |- 应用与模块分发（扩展自 PC 应用管理）
```

#### 1.4.2 多端实现策略

| 端 | 壳形态 | H5 模块承载 | 模块获取方式 |
|----|--------|-------------|--------------|
| **Android** | uni-app App | `web-view` + Bridge | zip 下载 → 校验 → 本地安装/升级 |
| **iOS** | uni-app App | `web-view` + Bridge | 同上；壳/原生热更遵守商店审核（仅资源类） |
| **H5** | uni-app H5（可 PWA） | 路由容器或 `web-view` | 弱安装=清单登记 + 可选预取；**不走 zip download 接口**；打开依赖 `moduleUrl`/同域 |
| **小程序** | uni-app 编译小程序 | `web-view` | **不做 zip 本地下载安装**；打开 PC 配置的合规在线 H5（`moduleUrl`）；可「添加到工作台」仅存入口元数据 |

> **统一约定**：业务功能优先 **H5 一次开发**；壳用 uni-app 收敛端差异；**模块安装能力按端降级，小程序明确砍掉本地装包**。

### 1.5 业务成功指标（产品侧）

> **定位**：下列为 **观测指标**（用于复盘与调优），**不作为 v1.0 上线门禁**；内测/灰度可另定基线。门禁以附录 C 功能验收为准。

| 指标 | 观测参考（上线 4 周后） | 统计口径 |
|------|--------------------------|----------|
| 壳 DAU / 移动端可登录用户 | 内测期观察趋势；正式推广后再定目标 | 当日完成登录并进入工作台 / 同期有移动登录权限的用户 |
| 模块打开率 | 观察项（初期常见 20%～60%） | 当日至少打开 1 次模块 / 壳 DAU |
| App 模块安装成功率 | 争取 ≥ 95%，持续优化至 98% | 校验通过且写入本地仓库 / 发起安装 |
| 模块二次打开耗时 P50 | ≤ 1.5s（已缓存/已安装） | 性能埋点 |
| 强制更新完成率 | 观察项；异常低于 80% 需排查 | 更新成功进入工作台 / 被拦截用户 |
| 模块白屏/加载失败率 | 争取 ≤ 2%，优化至 ≤ 1% | 打开失败或超时上报 / 打开次数 |
| 消息点击到达率 | 观察项 | 点击深链成功落地 / 消息点击次数 |

### 1.6 v1.0 范围分级（P0 / P1 / P2）

> **原则**：v1.0 保证 **能力基线**；四端追求「主路径可用」，**不要求能力完全等价**。排期以 P0 为上线必达，P1 同迭代尽力，P2 可顺延 v1.0.x / v1.1。

| 优先级 | 范围 | 说明 |
|--------|------|------|
| **P0（必达）** | 登录/会话/账户基础；RBAC 菜单权限；站内信列表与已读；工作台+应用中心+模块打开；**App zip 安装升级**；**H5 在线/弱安装打开**；Ticket 免登；Bridge **核心子集**；PC（Vue3）模块元数据+zip+`module_url`+发布门禁；壳强制/可选更新（App）；关于页版本环境；埋点 `shell_launch` + `module_open_*` | **已确认打穿：App + H5**；iOS 随 App 交付或冒烟；小程序主路径冒烟（完整对齐 P1/后续） |
| **P1（同迭代尽力）** | 小程序主路径对齐；四端体验打磨；全局搜索；扫一扫；反馈/FAQ；App 存储清理；埋点补齐；预览码+developing 白名单；断点续传 | 不影响 P0 验收可裁剪 |
| **P2（可顺延）** | 运营位真实数据；推送全通道；灰度；申请权限；包签名；设备列表；差量更新；完整测试大盘自动化 | 默认进 v1.1+ |

**四端策略（v1.0）**：**App（装包）+ H5（弱安装/在线）为 P0 参考实现**；小程序能力模型已定义，P0 冒烟、P1 对齐；Bridge 按端子集降级。

## 二、用户角色

| 角色 | 说明 | 核心诉求 |
|------|------|----------|
| **移动端用户** | 使用壳与已授权模块的业务用户（含模块使用场景，不另拆「模块使用者」） | 登录顺畅、菜单清晰、消息可达；App 可装可升、小程序可一键打开；缺权可理解 |
| **模块开发者** | 打包 H5 模块、联调 Bridge、提测发布 | 调试址、预览码、门禁与错误码清晰 |
| **应用运营** | 配置模块上下架、版本、灰度、推荐位与运营位 | 安全发布、可控灰度、可回滚、投放可配 |
| **权限运维** | 维护角色、菜单、模块可见权限 | 与 PC RBAC 一套权限码，避免双轨 |
| **平台管理员 / 超管** | 全局配置、强制升级、审计 | 管控、兜底、稳定性 |

## 四、各模块详细设计

### 4.1 多端壳与基础框架

#### 4.1.1 启动流程

| 步骤 | 行为 |
|------|------|
| 1. 冷启动 | 展示启动页；读取本地 Token、壳版本、已装模块清单 |
| 2. 环境检测 | 网络、端类型、系统版本、WebView/小程序基础库版本 |
| 3. 壳升级检查 | 调用升级接口；若 **强制更新** 则阻断进入（见 4.9） |
| 4. 会话校验 | 有 Token 则静默续期/拉用户信息；失败则进登录页 |
| 5. 权限与菜单 | 登录态下 `loadPermission`（菜单 + 权限码） |
| 6. 模块同步 | 比对已装模块与服务端版本，标记可更新；静默预下载可选 |
| 7. 进入工作台 | 渲染首页 Tab/工作台 + 消息角标 |

#### 4.1.2 端能力 Bridge（统一 API 名与子集）

> **鉴权类调用优先级（与 4.12.1 一致，避免与 Ticket 冲突）**：  
> 1）小程序 / 跨域在线 H5：**仅 Ticket 换票**，**不提供**向模块下发 Refresh Token；不宜依赖长期 `getAuthToken`。  
> 2）App 本地包：允许 `getAuthToken` 返回 **短时 Access Token**（或经壳换票）；**禁止**返回 Refresh Token；模块禁止把 Token 明文写入可被任意脚本读取的持久化存储。  
> 3）任意端：**禁止**把 Access/Refresh 长期放在 URL query。

| Bridge API | 说明 | App | H5 | 小程序 | v1.0 归属 |
|------------|------|-----|----|--------|-----------|
| `getDeviceInfo` | 设备/端/版本 | ✓ | 有限 | 有限 | P0 |
| `requestModuleTicket` | 向壳申请/刷新 moduleTicket | ✓ | ✓ | ✓ | P0 |
| `getAuthToken` | 短时 Access（**仅 App 本地包推荐**；见上方优先级） | ✓ | 不推荐 | **不提供**（用 Ticket） | P0 |
| `openModule` / `closeModule` | 打开/关闭模块 | ✓ | ✓ | ✓ | P0 |
| `navigate` | 壳内路由/深链 | ✓ | ✓ | 受限 | P0 |
| `setTitle` / `setNavBar` | 导航栏 | ✓ | ✓ | ✓ | P0 |
| `toast` / `loading` | 轻提示 | ✓ | ✓ | ✓ | P0 |
| `chooseImage` | 选图/拍照 | ✓ | 有限 | ✓ | P0 核心 |
| `getLocation` | 定位 | 授权后 | 授权后 | 授权后 | P0 核心 |
| `scanQRCode` | 扫码 | ✓ | 视能力 | ✓ | P1 |
| `share` | 分享 | ✓ | 有限 | ✓ | P1 |
| `downloadFile` | 下载（受策略限制） | ✓ | 受限 | 受限 | P2 |

**小程序 Bridge 能力子集（验收按此表，勿按 App 全集）：**

| 能力 | 小程序 v1.0 | 说明 |
|------|-------------|------|
| Ticket / 打开关闭 / 标题 / toast | ✓ | 主路径必达 |
| `chooseImage` / `getLocation` / `share` | ✓（经壳转 `uni.*`） | 受用户授权与基础库限制 |
| `postMessage` 实时双向 | **受限** | 依赖宿主实现；部分时机仅页面后退等才送达，模块需容忍延迟与 `BRIDGE_UNSUPPORTED` |
| `getAuthToken` | ✗ | 统一 Ticket |
| 本地文件类 / 任意下载 | ✗ | 返回 `BRIDGE_UNSUPPORTED` |

> 模块调用未实现的 Bridge 时：返回 `BRIDGE_UNSUPPORTED`，**不得白屏崩溃**。

### 4.5 权限

#### 4.5.1 三层控制

| 层 | 控制点 | 说明 |
|----|--------|------|
| 入口层 | Tab/菜单/应用中心卡片 | 无权限不可见 |
| 操作层 | 按钮/Bridge 敏感能力 | 前端隐藏 + 后端校验 |
| 数据层 | 模块配置/包地址下发 | 无权限不得返回下载地址 |

#### 4.5.2 与模块权限

| 规则 | 说明 |
|------|------|
| 可见 | 用户拥有模块声明的任一所需权限码（或模块标记 public+登录） |
| 可安装（App zip） | 另需 `mobile:module:install`（或角色默许） |
| 可添加（H5/小程序） | 弱安装/添加入口：**登录且模块可见即可**（不强制 `mobile:module:install`） |
| 可运行 | 每次打开仍校验权限；权限收回后禁止打开并提示 |
| 超管 | `super_admin` 兜底与 PC 一致 |

#### 4.5.3 缺权体验

- 深链打开无权限模块：提示「暂无权限」，提供返回工作台
- 权限中途变更：下次打开或心跳校验失败时关闭模块并提示
- **前端隐藏不等于安全**，模块包 URL、签名密钥不得暴露给无权限用户

#### 4.5.4 申请权限（体验增强，v1.1+）

| 项 | 说明 |
|----|------|
| 入口 | 应用中心详情对无权限用户展示「申请权限」（v1.0 仍为不展示） |
| 流程 | 提交原因 → 通知权限运维/管理员 → 审批通过后刷新权限并可打开 |
| 说明页 | 模块详情展示所需权限码的业务含义（非技术码堆砌） |

### 4.7 应用中心与模块生命周期

#### 4.7.1 核心概念

| 术语 | 定义 |
|------|------|
| **平台壳（Shell）** | uni-app 编译的多端宿主（App/H5/小程序） |
| **功能模块（Module）** | 可独立版本管理的 H5 业务能力：**App** 以 zip 交付；**H5** 弱安装/在线；**小程序** 以在线 URL 交付 |
| **安装（App）** | 下载 zip → 校验 → 解压/索引 → 写入本地模块仓库 → 生成入口 |
| **安装（H5）** | **弱安装语义（v1.0 明确）**：登记模块清单 + **可选**资源预取；不强制原生解压。未预取也可直接打开在线/同域资源；「已安装」= 用户确认添加且清单落库/本地索引 |
| **添加入口（小程序）** | 将模块元数据与在线 URL 记入工作台；**不下载 zip、不落本地包** |
| **升级** | App：更高版本包替换本地；H5：更新清单并刷新缓存；小程序：打开即拉运营侧当前在线版本（无客户端装包升级流） |
| **卸载 / 移除** | App：删本地包与入口；H5：清清单与缓存；小程序：仅移除工作台入口 |

#### 4.7.2 与 PC 应用管理关系

> **已确认（D07）**：移动壳为**独立仓**；**应用中心、菜单/权限、模块发布等配置在 drawStars-Vue3 复用改造**（如 `/home/manageHomePage/app`、菜单管理、角色绑权）。  
> PC 应用管理扩展为「移动模块」分发源：元数据、zip（App）、`module_url`（H5/小程序）、适配端、状态、升级策略。移动仓**不重建管理端**。

现有字段对齐与扩展：

| 字段/能力 | 现况（PC） | 移动端扩展（目标态） |
|-----------|------------|----------------------|
| name / description / icon / category | 已有 | 继续使用 |
| version / status | 已有 | 语义扩展为「当前发布版本」；明细见版本表 |
| file_path（zip/rar） | 已有 | **主要供 App**；新上传仅 zip + manifest；H5/小程序可空 |
| module_url（在线地址） | 无 | **H5/小程序打开依赖**（P0 含 H5 则必填策略按 platforms） |
| 多端适配 | 无 | `platforms`: android/ios/h5/mp-weixin… |
| 入口 | 无 | 包内 `entry`（如 `index.html`）；小程序用 `module_url` |
| 权限 | 无 | `permissionCodes[]` |
| 升级策略 | 无 | 强制/可选、最低壳版本、灰度（装包端）；小程序侧靠发布切换在线资源 |
| 签名 | 无 | 包哈希 + 签名校验（装包端） |

#### 4.7.3 模块状态（运营侧）

| 状态 | 值 | 对移动端影响 |
|------|-----|--------------|
| 草稿 | draft | 不可见 |
| 开发中 | developing | **v1.0（P1）**：仅测试白名单 / 模块开发者可见，配合预览码与调试址；未配白名单则不可见 |
| 未发布 | unpublished | 不可见 |
| 已发布 | published | 应用中心可见（权限内） |
| 已下架 | offline | App 不可新装；小程序/H5 不可新打开（已添加入口提示停用）；已装策略可配 |

#### 4.7.4 用户侧模块状态机

**App / H5（装包或缓存）：**

```
未安装 ──安装成功──► 已安装 ──检测到新版本──► 可更新
                         |                        |
                         +──打开运行◄─────────────+
                         |
                         +──卸载──► 未安装

强制下架 / 无权限 ──► 已禁用（不可打开）
```

**小程序（无本地装包）：**

```
未添加 ──添加工作台 / 直接打开──► 可打开（在线）
              |
              +──移除入口──► 未添加

下架 / 无权限 / 无 module_url ──► 不可打开
```

#### 4.7.5 应用中心功能

| 功能 | App / H5 | 小程序 |
|------|----------|--------|
| 列表/搜索/分类 | ✓ 权限过滤 | ✓ 权限过滤 |
| 详情 | App：包大小+更新日志；H5：弱安装说明+更新日志 | 在线说明、版本号；**不展示下载包体** |
| 主操作 | App：安装/打开/更新；H5：添加（弱安装）/打开 | **打开**（在线）；可选「添加到工作台」 |
| 卸载/移除 | App：卸本地包；H5：清清单/缓存 | 仅移除工作台入口 |
| 我的应用 | App 已装+更新角标；H5 已添加列表 | 已添加入口列表 |
| 更新日志时间线 | 详情页展示历史 `releaseNotes`（最近 N 条） | 同左 |
| 收藏 | 收藏模块便于找回（v1.1） | 同左 |
| 依赖声明 | 详情展示依赖模块；缺依赖时引导先装/先打开（v1.1） | 仅提示在线依赖 |

#### 4.7.6 安装/升级规则

| 规则 | 说明 |
|------|------|
| 分端适用范围 | **下列 zip 装包规则仅约束 App；H5/小程序不适用 zip 下载**（H5=弱安装；小程序=在线打开） |
| 包校验 | 校验 `sha256`（及签名，v1.0 至少哈希）；失败则中止并提示 |
| 壳版本约束 | `minShellVersion` / `maxShellVersion`；不满足则引导先升壳 |
| 端适配 | 模块未声明当前端则不展示或不允许安装/打开 |
| 版本比较 | 使用 **SemVer**（MAJOR.MINOR.PATCH）比较，**禁止**纯字符串比大小；预发布标签规则见附录或工程约定 |
| 幂等 | 同一 `moduleCode@version` 重复安装视为成功 |
| 断点续传 | 大包支持续传（App **P1**） |
| 存储上限 | 本地模块总大小超限时提示清理（App） |
| 防重 | 同一模块同时仅一次安装任务 |
| 回滚 | 见 **4.10.4** 决策表 |
| 小程序/H5 打开 | 必须存在合法 `module_url`；打开前校验权限；**禁止下发 zip 下载地址** |

#### 4.7.7 模块包规范（manifest）


### 4.8 H5 模块运行时

#### 4.8.1 加载方式

| 端 | 加载策略 |
|----|----------|
| Android/iOS（uni-app App） | 优先 `web-view` 加载本地已安装包；可配置远程调试地址（仅开发包） |
| H5（uni-app H5） | 路由容器或 `web-view`；「安装」= Cache Storage / IndexedDB 资源预取 |
| 小程序（uni-app 编译） | **仅** `web-view` 打开 `moduleUrl`（已配置业务域名）；**不下载 zip、不本地解压、不离线装包** |

#### 4.8.2 运行时职责

| 职责 | 说明 |
|------|------|
| 注入上下文 | userId、roles、permissions、locale、theme、shellVersion、moduleVersion（非敏感） |
| 鉴权 | 打开前走 Ticket（4.12.1）；App 本地包可辅以短时 `getAuthToken`；规则见 4.1.2 |
| 导航 | 模块内 SPA 路由；顶栏返回先模块内回退，再关闭容器 |
| 通信 | uni-app `web-view` ↔ 壳：`postMessage` + 约定协议；小程序按子集降级 |
| 错误页 | 加载失败、校验失败、权限失败统一错误页，可重试 |
| 性能 | 记录 TTI、白屏；超时（默认 15s）可杀进程并上报 |
| WebView 栈 | **v1.0 默认单模块栈**：同时仅一个业务模块 WebView；打开新模块前关闭或盖住旧模块（避免多 WebView 内存爆）。多模块并行为 v2.0+ 预留 |

#### 4.8.3 安全沙箱

| 项 | 要求 |
|----|------|
| 域名 | 仅允许白名单请求；WebView 限制任意 file 越权 |
| XSS | 壳不对模块 HTML 做不安全拼接；Token 不进 URL |
| 敏感 Bridge | 按 `bridgePermissions` + 用户系统授权双重控制 |
| 第三方脚本 | 模块打包审核；禁止运行时随意加载未知脚本（可配） |

#### 4.8.4 深链

格式建议：`ds://module/{moduleCode}?path=/xxx&query=...`

| 场景 | 行为 |
|------|------|
| App/H5 已装 + 有权限 | 打开到指定 path |
| App/H5 未装 + 有权限 | 详情页/一键安装后打开 |
| 小程序 + 有权限 | 直接 `web-view` 打开 `moduleUrl`（可带 path 查询参数） |
| 无权限 | 缺权提示 |
| 壳未装（外链） | 引导下载 App / 打开 H5 / 跳转小程序对应入口 |

### 4.9 平台壳自动升级

#### 4.9.1 版本模型

| 字段 | 说明 |
|------|------|
| `shellVersion` | 语义化版本 `MAJOR.MINOR.PATCH`（uni-app 壳版本） |
| `buildNumber` | 端构建号 |
| `platform` | android / ios / h5 / mp-* |
| `channel` | 应用商店/官网/企微等渠道 |
| `minSupportVersion` | 低于此版本必须升级 |
| `latestVersion` | 最新版本 |
| `forceUpdate` | 是否强制 |
| `packageUrl` / 商店地址 / `wgtUrl` | 分端不同；App 可区分整包与 wgt |
| `releaseNotes` | 更新说明 |
| `checksum` | 安装包/wgt 校验（非商店分发时） |

#### 4.9.2 策略

| 策略 | 行为 |
|------|------|
| 强制更新 | 启动检测拦截；仅保留退出/更新；不可进工作台 |
| 强推可选 | 弹窗推荐更新，可「下次再说」（冷却期可配，默认 24h） |
| 静默提示 | 关于页红点或设置项提示 |
| App（uni-app） | 优先资源热更（`wgt`，合规范围内）；必要时整包/跳转应用商店 |
| H5 壳 | 资源/Service Worker 更新；提示刷新 |
| 小程序 | 微信等平台更新机制 + 基础库兼容提示；**业务模块无壳内装包升级，随 `moduleUrl` 发布切换** |

#### 4.9.3 流程

```
启动/设置页检查更新
  → GET /api/mobile/shell/checkUpdate
  → 无需更新：继续
  → 可选更新：弹窗 → wgt/整包下载或跳转商店 → 安装
  → 强制更新：阻断 → 同上
```

| 规则 | 说明 |
|------|------|
| 检查频率 | 冷启动必查；前台回前台可节流（默认 ≥ 30min） |
| Wi-Fi | 大包可默认仅 Wi-Fi 下载（用户可改） |
| 失败重试 | 指数退避；失败不死循环弹窗 |
| iOS | 优先跳转 App Store；`wgt` 仅限资源，避免违规热替换原生代码 |
| Android | 可 wgt / 应用内 APK（渠道允许）或跳转应用商店 |
| 小程序 | 不走本接口装包；提示用户重启/等待平台更新即可 |

#### 4.10.2 发布状态机（模块版本）

```

                |
                +──► 灰度中(graying) ──全量──► published
published ──下架──► offline
任意非当前版本可设为「回滚目标」──► 重新 published
```

#### 4.10.3 运营约束

| 约束 | 说明 |
|------|------|
| 版本号单调 | 同一 `moduleCode` 新版本必须 **SemVer 大于** 已发布最大版本（热修走 PATCH） |
| 强制更新模块 | 可标记 `forceUpdate`，旧版打开时阻断并升级 |

| 发布门禁 | 见 **4.12.3**，发布动作强制执行 |
| 存量迁移 | 见 **4.10.5** |

#### 4.10.4 灰度 / 强制更新 / 回滚决策表

| 场景 | 策略（v1.0 默认） |
|------|-------------------|
| 全量发布 + 非强制 | 客户端提示可更新；用户可继续用旧版 |
| 全量发布 + 强制 | 打开模块前阻断，必须升到当前发布版 |
| 灰度中（v1.1） | 仅命中用户看到新版本；未命中仍用上一全量版 |
| 灰度中误开强制 | **禁止**：门禁拦截「灰度 + forceUpdate」组合，或强制仅作用于灰度命中用户且文案标明 |
| 运营回滚当前指针 | 服务端 `current_version` 指向旧版；**已装更高版本客户端默认保留本地包**，提示「服务端已回滚，可继续使用本地版或重装对齐」 |
| 回滚 + 强制对齐 | 运营显式勾选「强制对齐回滚版」后，客户端按强制更新流程降级/重装（慎用，v1.1+） |
| 下架 | 不可新装/新开；已装是否可开由配置 `allowOpenAfterOffline`（默认 false） |

#### 4.10.5 现有 PC 应用管理迁移

| 现况（`appManage`） | 目标态 | 策略 |
|---------------------|--------|------|
| 单表应用 + `version`/`file_path`/`status` | `mobile_module` + `mobile_module_version` | 一应用一行模块；历史 `file_path` 迁为版本 v1 记录 |
| status: draft/developing/unpublished/published | 模块 status + 版本 status 分离 | 映射表落地时固化；旧「published」→ 模块 published + 版本 published |
| rar 包 | 仅保留兼容读取 | **新上传仅 zip + manifest**；rar 标注废弃 |
| 无 `module_url` | 版本表必填策略按 platforms | 含小程序则补录 URL 后方可发布 |
| 无权限码 | `permissionCodes` / 关联表 | 运营补录前可仅超管可见（过渡期） |

### 4.12 协议与安全

> 本章约定模块接入的硬协议与安全基线，**v1.0 必须落地**（增强项单独标版本）。

#### 4.12.1 模块免登 / SSO Ticket

> 壳持有用户会话。与 4.1.2 鉴权优先级一致：小程序/跨域 H5 **只走 Ticket**；App 本地包可 Ticket 或短时 `getAuthToken`。  
> **禁止**模块持有 Refresh Token；**禁止** Access/Refresh 长期出现在 URL query。

| 步骤 | 说明 |
|------|------|
| 1. 打开模块前 | 壳申请一次性 `moduleTicket`（绑定 userId、moduleCode、platform、短 TTL 60～120s） |
| 2. App 本地包 | 推荐启动参数带一次性 `ticket`；或 Bridge `getAuthToken` 取短时 Access |
| 3. 小程序/在线 H5 | `moduleUrl` 仅可附加一次性 `ticket`/`code`；**不调用** `getAuthToken` |
| 4. 换票 | `POST /api/mobile/module/exchangeTicket`（可由模块后端调用）→ 校验后发模块短时凭证或建会话 |
| 5. 过期 | Bridge `requestModuleTicket` 续票；壳会话失效则关模块回登录，成功后深链回跳 |
| 6. 安全 | ticket 一次性或限次；绑定 moduleCode；HTTPS only；下载/CDN 见 4.12.6 |

```
壳(已登录) → 申请 moduleTicket → 打开 Runtime
                → 模块用 ticket 换票/建会话 → 业务请求
                → 过期 → requestModuleTicket → 失败则回壳登录
```

打开时序见 **附录 J**。

#### 4.12.2 Bridge 消息协议

**传输**：uni-app `web-view` ↔ 壳页面，`postMessage`；壳转调 `uni.*`。  
**版本**：握手时交换 `bridgeApiLevel`（整数），双方按最小公共级别能力集交互。

**请求（模块 → 壳）示例：**

```json
{
  "v": 1,
  "type": "call",
  "id": "uuid-or-seq",
  "method": "chooseImage",
  "params": { "count": 1 },
  "moduleCode": "survey.mobile",
  "ts": 1735689600000
}
```

**响应（壳 → 模块）示例：**

```json
{
  "v": 1,
  "type": "result",
  "id": "uuid-or-seq",
  "ok": true,
  "data": { },
  "error": null
}
```

**失败时 `error`：**

```json
{
  "code": "BRIDGE_UNSUPPORTED",
  "message": "当前端不支持该能力",
  "retryable": false
}
```

| 规则 | 说明 |
|------|------|
| 超时 | 默认 15s 无响应则模块侧失败，错误码 `BRIDGE_TIMEOUT` |
| 权限 | 方法不在模块 `bridgePermissions` 内 → `BRIDGE_DENIED` |
| 用户拒绝 | 系统授权拒绝 → `BRIDGE_USER_DENIED` |
| 未实现 | `BRIDGE_UNSUPPORTED`，**不得白屏** |
| 事件推送 | 壳 → 模块可用 `type: "event"`（如 `session.kicked`、`theme.change`） |
| 完整错误码 | 见附录 H |

#### 4.12.3 发布门禁（PC）

上传/发布版本前服务端 + 管理端校验，**不通过不可 publish**：

| 校验项 | 说明 |
|--------|------|
| manifest | 可解析；`moduleCode`/`version` 与记录一致 |
| platforms | 非空；与勾选适配端一致 |
| checksum | 与文件计算值一致 |
| module_url | 若 `platforms` 含 **h5 或小程序**：必填且为 https；可选探活（HEAD/GET） |
| 版本单调 | 新版本 **SemVer >** 已发布最大版本 |
| 灰度+强制 | 非法组合按 4.10.4 拦截或受限 |
| 权限码 | `permissionCodes` 已在菜单/权限体系中存在（警告或阻断可配） |
| 业务域名提示 | 发布含小程序时，提示运营确认微信公众平台业务域名已配置 |
| zip 存在性 | `platforms` 含 android/ios 时 `file_path` 必填 |

#### 4.12.6 模块包 CDN 与下载鉴权

| 项 | 说明 |
|----|------|
| 存储 | zip 存对象存储/CDN；管理端上传后写 `file_path` |
| 下载凭证 | App 调 `/download` 获取 **短时签名 URL**（建议 5～15 分钟）；禁止对无权限用户返回永久公网直链 |

#### 4.12.7 H5 / 在线打开跨域与换票约束（P0）

| 项 | 说明 |
|----|------|
| 打开方式 | H5 壳优先同域或可配置的业务域名加载 `moduleUrl`；跨域时用 `web-view`/iframe 需评估 Cookie 与 postMessage |
| Ticket | 仅短时 query/`postMessage` 注入；模块后端 `exchangeTicket` 应在**可信 API 域**完成，勿依赖第三方任意域读壳 Cookie |
| CORS | 模块 API 域对壳/换票来源做白名单；禁止 `*` + Credential 组合 |
| 小程序 | 另受业务域名限制；P0 以冒烟为准，完整对齐 P1 |

### 6.3 关键页面说明

#### 登录页

- 主操作：账号密码 / 短信 / 微信（按端）
- 展示协议勾选；错误与锁定态提示
- 已登录访问则进工作台

#### 工作台

- 已装应用宫格 + 最近使用；顶栏搜索/扫一扫入口
- 空态引导应用中心；下拉同步模块更新状态
- 预留运营 Banner 槽位（v1.0 可空）

#### 应用中心

- 分类 + 列表/卡片；支持进全局搜索
- 详情：更新日志时间线；按钮分端（装包 vs 在线打开）
- 无权限 v1.0 不展示；v1.1+ 可「申请权限」

#### 模块容器（uni-app `web-view`）

- 打开前完成 ticket 换票（见 4.12.1）
- 顶栏：返回、标题（`setTitle`）；加载中/失败/强制更新遮罩
- 小程序：业务域名未配置、加载失败明确文案
- 禁止容器内随意跳出未白名单外链

#### 全局搜索 / 扫一扫 / 反馈

- 搜索：分组结果与空态
- 扫码：深链/预览码；失败三分文案
- 反馈：文本+可选日志；提交成功提示

#### 消息中心

- 列表分页、未读高亮、点击跳转
- 空态与失败重试

#### 我的 / 账户

- 头像昵称、设置、存储清理、反馈帮助、关于（版本/环境/构建号）、检查更新、退出登录

#### PC 应用管理扩展（drawStars-Vue3）

- 在本仓库复用改造，不在移动独立仓重建
- 保留现有列表/创建/上传包能力；按 4.10.5 迁移
- P0：适配端、**关联权限表**、`module_url`、版本历史、强制更新、发布门禁、壳发布
- P1：预览码、developing 白名单
- v1.1：运营位、灰度

## 七、接口概要

> 网关前缀 `/api`。统一响应 `{ status, msg, data }`。移动端接口需登录鉴权（除登录与公开协议）。  
> **现网对齐**：下表路径为逻辑名。若现网已有登录/用户接口（如历史 `userApi`/`login` 等），**优先复用现网路径与 Token 方案**，仅增量 `/api/mobile/*` 与应用扩展；落地前输出「现网路径映射表」作为接口设计附件。

## 八、非功能性需求

| 维度 | 要求 |
|------|------|
| **性能** | 壳冷启动至工作台可交互 ≤ 3s（中端机/正常网）；模块二次打开 ≤ 1.5s（已缓存） |
| **包体** | 壳安装包精简；模块默认 ≤ 50MB；列表接口首屏 ≤ 500ms（P95） |
| **并发** | 登录/安装/已读等写操作防重；模块下载任务队列化；忽略过期列表响应 |
| **兼容性** | uni-app 当期稳定版；Android 8+、iOS 13+、主流手机浏览器近 2 年版本、微信小程序基础库按当期 LTS；各端 `web-view` 冒烟清单 |
| **安全** | HTTPS；证书校验；Token 安全存储；模块包哈希/签名；权限服务端强校验；下载 URL 短时签名；禁止敏感参数进 URL |
| **隐私合规** | 权限最小化；隐私政策；推送/定位等运行时申请；分端商店合规文案 |
| **可用性** | 强制更新与模块校验失败有明确恢复路径；关键路径离线提示 |
| **可观测** | 启动、安装成功/失败、升级、模块白屏/崩溃、Bridge 失败上报；事件字典见附录 G |
| **国际化** | 壳文案跟随现有 i18n；模块自行负责（v1.0 中文优先） |
| **体验** | 搜索/扫码/反馈主路径可用；关于页可定位环境与版本；存储可清理 |

### 9.1 扩展点

| 扩展点 | 说明 |
|--------|------|
| 登录提供者 | 短信/微信/Apple 等可插拔（uni 登录能力封装） |
| Bridge 能力 | 按 `bridgeApiLevel` 注册；底层优先 `uni.*`，模块经 Runtime 协议调用 |
| 模块加载器 | App 本地包 / H5 缓存 / 小程序在线 `web-view` 三套适配器 |
| 推送通道 | APNs、厂商推送、小程序订阅消息适配 |
| 升级策略 | 壳：wgt/整包/平台更新；模块：装包端升级 vs 小程序在线切换 |
| 菜单客户端过滤 | `client=mobile` 与端类型过滤，不影响 PC 菜单 |
| Ticket 换票 | 模块后端可独立校验 ticket，不强迫模块与壳同域 |
| 运营位 | Banner/推荐位配置与模块解耦，按端与角色投放 |

### 9.2 新 H5 模块接入步骤

1. 按 manifest 打包 zip（App）并部署 HTTPS 静态资源（`moduleUrl`，供 H5/小程序）  
2. 实现 Bridge（附录 H）与 Ticket 换票（4.12.1）；权限码写入关联表所需清单  
3. 在 **drawStars-Vue3** 应用管理创建模块：关联权限、适配端、上传 zip、填写 `module_url`，过门禁发布  
4. 角色绑定菜单/权限（菜单带 `moduleCode`）  
5. **P0**：App 安装打开 + H5 弱安装/在线打开；小程序冒烟  
6. （可选 P1）深链、预览码  
7. 埋点：至少 `module_open_*`  

### 9.3 与现有系统集成

| 集成对象 | 集成方式 |
|----------|----------|
| 用户/登录 | 复用平台账号体系与 Token；模块走 ticket 免登 |
| RBAC | 复用角色—菜单—权限码；移动菜单可标记端类型与 moduleCode |
| PC 应用管理 | 在 **drawStars-Vue3** 扩展为模块分发源（zip + module_url + 门禁 + 关联权限） |
| 通知管理 | **复用通知表**；移动 BFF 提供 messages API；推送点击走深链（推送通道 v1.1） |
| 日志体系 | 发布审计、登录风控、安装/打开/Bridge 失败、反馈与 telemetry |
| 任务管理 | 待办角标/消息聚合（v1.1）；深链进任务模块 |

## 附录 J：打开模块时序（Ticket）

```
用户点击模块
  → 壳校验权限 / 强制更新 / 下架策略
  → POST /api/mobile/module/ticket { moduleCode, platform }
  → 取得 moduleTicket
  → Runtime 打开
       ├─ App 本地包：加载本地 entry；注入 ticket 或允许 getAuthToken(短时 Access)
       └─ 小程序/H5：web-view 打开 moduleUrl?ticket=...
  → 模块（或模块后端）POST exchangeTicket
  → 获得模块会话 / 短时凭证
  → 业务请求
  → 若 401：requestModuleTicket → 换票；仍失败则关模块回壳登录
  → 登录成功：按深链回跳原 moduleCode + path
```
